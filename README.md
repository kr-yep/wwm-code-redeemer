# 燕雲兌換助手

適用於 Steam 繁中版《燕雲十六聲》的 Windows 獨立程式。自動收集你設定的 Discord 討論串中的文字兌換碼、逐筆兌換，並依角色保存進度；下次開啟可接續處理。

不需要 Codex、Computer Use、Python、API 金鑰或 Discord Token。目前版本為 **v0.5.2**。

## 下載與環境

- [下載最新版本](https://github.com/kr-yep/wwm-code-redeemer/releases/latest)：展開 Assets，下載 ZIP，解壓縮後開啟「燕雲兌換助手.exe」。不需下載或編譯原始碼。
- Windows 10/11 64 位元，已安裝英文及繁體中文 OCR 語言功能。
- Discord 桌面版使用繁中介面，自己的帳號需有指定討論串的閱讀權限。
- 遊戲使用視窗化或無邊框模式。**建議將遊戲解析度設為 1920 × 1080**；目前畫面辨識及操作位置以此介面實測，其他解析度尚未完整驗證。
- 若遊戲以系統管理員執行，請右鍵助手，選擇「以系統管理員身分執行」。

## 開始使用

1. 在 Discord 開啟你有閱讀權限的兌換碼討論串，複製該討論串連結。
2. 在助手輸入遊戲左下角的角色 ID，按 Enter 或點其他位置，載入該角色進度。
3. 把網址貼到主畫面角色 ID 下方的 **「Discord 討論串連結」** 欄位，按 Enter 保存，或直接按「掃描頻道」保存並掃描。貼的是 `https://discord.com/channels/…/…` 網址，不是討論串訊息內容。舊版使用者會自動顯示既有本機來源。
4. 將遊戲停在「設定 → 其他 → 兌換碼」，保持角色 ID 可見。
5. 按「快速兌換」或「完整兌換」。執行期間請暫停其他滑鼠鍵盤操作；需要停止時按 **F10**。

掃描和兌換分開執行。已有掃描紀錄時，可直接開始兌換，不必重新掃描。

來源網址只存在本機。已有掃描紀錄的角色不可改成另一個討論串，以免混入不同來源的進度。

## 四個操作

| 按鈕 | 功能 |
| --- | --- |
| 掃描頻道 | 首次掃描全部文字歷史；之後只補上次完整進度以後的新訊息。 |
| 快速兌換 | 使用已掃描紀錄，處理按下按鈕時往回 **15 天**內訊息中的待兌換碼。 |
| 完整兌換 | 使用已掃描紀錄，處理全部待兌換碼，不限制日期。 |
| 停止 | 保存目前進度並停止；也可按 F10。 |

沒有本批上限。兩種兌換模式都會持續處理符合範圍的待兌換碼，直到完成、手動停止或遇到無法確認的情況。操作會使用滑鼠、鍵盤和剪貼簿。

## 進度如何保存

掃描以訊息 ID 記錄完成位置。例如上次掃到 9/21，下次會補上該位置之後的訊息，包含 9/21 稍晚新增的內容。相鄰頁需有重疊；掃描中斷或漏頁時不推進完成位置，下次仍會補齊。若原位置的訊息被刪除，會往回核對至討論串起點。

每組碼分別保存結果。成功、已領取、已過期、無效及單碼已達上限都會跳過；「待確認」不會自動重送。右鍵點選清單可查看結果截圖、來源訊息，以及手動確認狀態或重新嘗試。

增量掃描不重新檢查更早歷史中的編輯。只收集討論串內可讀的文字，不辨識 Discord 圖片，也不追蹤外部連結。

## 更新、備份與分享

進度保存在執行檔旁的 `data/`，依角色 ID 分開。

- 更新：先關閉助手，再替換程式，**保留 data 資料夾**。
- 備份或換電腦：搬移整個程式資料夾，包含 data。
- 分享給朋友：傳原始 ZIP；內含程式與使用說明，不含你的角色、訊息、進度或截圖。

## 遇到問題

| 情況 | 處理方式 |
| --- | --- |
| 無法操作遊戲 | 確認遊戲與助手權限相同，並停在兌換設定頁；建議使用 1920 × 1080。 |
| 無法辨識角色或輸入 | 保持角色 ID 與兌換介面可見，不要讓其他視窗遮住；查看下方紀錄。 |
| 結果顯示「待確認」 | 右鍵查看結果截圖，依實際遊戲回應手動確認；不要直接假定成功。 |
| 掃描未完成 | 確認 Discord 開在指定討論串後，重新按「掃描頻道」。原有完成位置會保留。 |

最近錯誤在 `data/last-error.txt`；檢查及結果截圖位於 `data/profiles/<角色 ID>/`。更多操作細節見 [USAGE.md](USAGE.md)，同份內容隨 ZIP 提供為「使用說明.txt」。

## 開發與驗證

- `src/MainForm.cs`：四按鈕介面與角色載入。
- `src/Store.cs`、`src/ScanCoverage.cs`：文字擷取、結果紀錄與掃描接合。
- `src/Runner.cs`、`src/Desktop.cs`、`src/Ocr.cs`：Discord 掃描、遊戲操作與本機 OCR。
- `src/RedemptionWorkflow.cs`、`src/SelfTest.cs`：逐碼流程與離線測試。

執行 `./build.ps1` 建置；執行 `./package.ps1` 建置並產生分享包，打包時以白名單排除私人資料。使用 Windows 內建 .NET Framework 編譯器。

程式參數 `--self-test <結果檔> [既有 journal.jsonl]` 執行離線測試；歷史紀錄先複製到暫存區，不修改原始進度。

已實測連續兌換、返回接續、角色辨識備援及無新增訊息時的增量掃描。15 天邊界、跨頁接合、漏頁停止及中斷復原等離線測試通過；有新訊息的跨頁增量尚待實機驗證。

建置產物及私人資料不納入 Git。公開原始碼與下載包不含預設伺服器／討論串位置、角色 ID、實際訊息、截圖或登入憑證；測試使用虛構資料。詳細資料範圍見 [PRIVACY.md](PRIVACY.md)。
